# Homebrew tap for CLI Toolkit for Jira

```sh
brew install user17745/tap/jira-cli-toolkit
brew upgrade jira-cli-toolkit
```

Installs the `jira` command from [CLI Toolkit for Jira](https://github.com/User17745/jira-cli-toolkit), an independent command-line tool for Jira Cloud. Supports macOS 15+ on Apple Silicon and Intel, and Linux x86_64 (glibc 2.39+).

The formula installs the native binary attached to each stable GitHub release. A [daily workflow](.github/workflows/update.yml) picks up new releases: it takes each binary's SHA-256 from the release manifest and verifies its GitHub build attestation before updating the formula. `Formula/jira-cli-toolkit.rb` is generated by `scripts/update_formula.py`.

CLI Toolkit for Jira is independently maintained and is not affiliated with Atlassian. Jira is a trademark of Atlassian.
